# 工作区分组、可折叠侧栏与批量添加项目

## 交互

- 点击左上角锚点应用图标展开或收起完整侧栏。宽窗口默认展开；1100px 及以下默认显示图标栏，展开时覆盖在正文上方，不压缩资源列表和编辑器。
- 窄窗口可点击遮罩、按 Escape 或选择导航项收起侧栏。列表与正文继续使用 3:7 比例，并保留最小宽度、主题、14–22px 字号设置和隐藏滚动条。
- “工作区”位于“项目”上方。下拉框切换自定义分组，旁边的更多菜单可新建、重命名、删除工作区；默认工作区不可删除。
- 工作区名称去除首尾空白，限 1–80 个字符，禁止控制字符和同名分组（忽略大小写）。错误在名称表单内显示，输入不会丢失。
- 项目搜索只搜索当前工作区；项目名称保持可见，长名称省略并提供悬停提示。点击项目直接进入配置，无需位置弹窗。
- “添加项目”打开原生目录选择器，可用系统的 Command/Ctrl/Shift 多选。一次添加一个新项目直接进入它；批量选择保持当前位置。已有项目加入其他工作区时复用同一份配置和身份。
- 同次选择重复目录会去重；已在当前工作区中的项目会计数提示。有效项目正常添加，无效目录集中显示路径与错误，可处理后重试。取消选择不修改数据。
- 项目菜单的“从工作区移除”只解除当前关联，保留其他工作区和磁盘文件。若最后一个关联被移除，则取消项目登记。未保存项目草稿需先保存或放弃。
- 删除工作区仅删除分组，保留项目登记和文件；只属于该分组的项目转入默认工作区，已属于其他分组的项目继续保留原有关联。

## 状态与共享

工作区是项目分组，不是新的文件根目录。全局配置、资源库、设置和操作记录仍然共用；一个项目的资源仅扫描一次，多个工作区引用相同项目 ID，因此编辑、备份和历史不会产生副本。

`skilldock.workspace.v1` 向后兼容增加 `workspaceId` 和 `workspaceLocations`，保存上次分组及每个分组的导航位置。切换分组恢复其上次位置；位置不属于该组时回到全局。工作区或项目失效时安全回退。

资源列表筛选、选中项与临时草稿仍按物理项目位置维护；共享项目在不同分组中打开会恢复同一份草稿。跨分组定位草稿时会自动切换到包含项目的工作区。切换分组不会写入文件、清空草稿或额外创建备份。草稿内容、搜索和滚动仍仅保留在当前会话。

## 数据与接口

SQLite `user_version` 从 1 升到 2，幂等创建：

- `workspaces(id, name)`：自定义工作区，内置稳定 ID `default`。
- `workspace_projects(workspace_id, project_id)`：多对多关联，复合主键去重，外键级联清理关联。

初始化在事务内完成。既有项目或孤立登记自动关联默认工作区；不重建项目 ID、不搬动目录、不修改技能与规则文件。重启不把其他工作区的项目重复归入默认工作区。

新增 Tauri 命令：

| 命令 | 参数 | 返回 |
| --- | --- | --- |
| `create_workspace` | `name` | `Overview` |
| `rename_workspace` | `id`, `name` | `Overview` |
| `delete_workspace` | `id` | `Overview` |
| `add_projects_to_workspace` | `workspaceId`, `paths[]` | `AddProjectsResult` |
| `remove_project_from_workspace` | `workspaceId`, `projectId` | `Overview` |

`Overview.workspaces[]` 包含 `id`、`name`、`projectIds[]`。`AddProjectsResult` 包含新概览、`addedProjectIds[]`、`alreadyPresent` 和逐路径的 `failures[]`；目录校验独立执行，有效项目登记与分组关联在同一事务内写入，完成后统一扫描一次。选择器打开时捕获目标分组，防止异步结果加入错误分组。

原 `add_project` / `remove_project` 接口继续兼容；新界面使用分组接口。资源读写保护、指纹校验、备份及退出/更新草稿保护沿用现有逻辑。

## 验证（2026-10-15）

- 前端 56 项测试：包含工作区筛选、共享草稿、跨分组草稿定位、导航恢复、管理表单校验、默认分组保护、分组删除回退、一次批量添加/取消/部分失败、混合新旧项目不跳转、作用域移除，以及窄窗口图标展开和 Escape 关闭。
- Rust 36 项测试：包含旧数据库升级与重复打开、项目共享身份与唯一扫描、重复路径去重、部分失败、无效分组拒绝、移除最后关联仍保留文件、删除分组迁回默认、名称校验与重启持久化；原资源 CRUD、冲突、备份恢复测试继续通过。
- TypeScript/Vite 构建、Rustfmt、Clippy（`-D warnings`）及 `git diff --check`。
- macOS 1040px 原生隔离包实测：图标展开完整侧栏、项目名称、切换默认/公司工作区、点击项目直接进入与 3:7 编辑布局；原生目录选择器同时选中两个项目，验证“新增 1 个、已存在 1 个”，无重复登记。使用独立应用标识和合成目录，不改真实项目配置。
- Windows 原生目录选择及所有字号组合尚未实机验收；原有前端 chunk 大小提示仍存在。本次功能随 v0.1.8 发布；Windows/macOS 安装包与签名由现有 GitHub Actions 工作流构建。
