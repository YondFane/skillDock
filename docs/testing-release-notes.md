# SkillDock v0.1.8

## 中文

- 简化主工作区，支持直接编辑保存、快捷键保存和同一资源多文件一次保存。
- 新增自定义工作区、跨工作区共享项目、可折叠侧栏及项目目录多选。
- 切换项目和文件时保留会话草稿与筛选状态，补齐退出和安装更新前的草稿保护。
- 新建、导入和收录减少重复确认，保留写入校验、完整备份与冲突提示。

安装包：Windows x64 / macOS 13+（Apple Silicon 与 Intel）。Windows 未配置发行者证书；macOS 使用 ad-hoc 签名、未公证。

## English

- Simplify the main workspace with direct editing, save shortcuts, and one save for multiple files in a resource.
- Add custom workspaces, shared projects across workspaces, a collapsible sidebar, and multiple project-folder selection.
- Preserve session drafts and filters across projects and files, with draft protection before quitting or installing updates.
- Reduce repeated confirmations for creation and imports while retaining validation, complete backups, and conflict detection.

Installers: Windows x64 / macOS 13+ (Apple Silicon and Intel). Windows has no publisher certificate; macOS is ad-hoc signed and not notarized.
