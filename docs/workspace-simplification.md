# 操作简化：项目工作区与临时草稿

## 目的与最终交互

日常维护本地技能与规则按“选择位置 → 打开资源 → 编辑保存”完成，减少页面跳转、反复筛选和确认弹窗。

- 首次默认全局配置。左侧直接选择项目，工作区切换全部工具、Claude、Codex；单次添加一个项目后直接进入该项目，批量添加保留当前位置；从当前工作区移除保留项目文件。有未保存项目草稿时先处理草稿再移除。
- 资源库、历史和设置保留辅助入口。主工作区取消统计卡片与大段标题，列表与内容按 3:7 分配宽度，1100px 以下默认折叠导航，点击锚点图标展开完整侧栏；窄窗口采用覆盖层，不挤压正文。保留主题、字体设置与隐藏滚动条。
- 普通保存和 Cmd/Ctrl+S 直接执行校验与写入。编辑器的“查看差异”是可选操作，可比较打开时内容或磁盘当前内容；列表筛选不会因保存清空，过滤后不匹配的已打开资源继续显示并提示。
- 新建在右侧面板填写，继承当前位置与工具；选择全部工具时必须明确目标工具。Codex 的已有指令文件不覆盖，可直接打开实际发生冲突的文件。
- 本地收录、本地配置收录到资源库一次提交完成，不改变原始文件。成功消息提供查看资源入口。删除保留一次简短确认，历史恢复保留完整差异确认。
- 操作菜单点击外部或按 Escape 自动收起。保存期间锁定当前资源，仍可查看其他资源，重复提交被阻止。
- 隐藏文字与图标居中样式仅在侧栏折叠时生效，展开后显示项目名称和工作区选择。长名称保留省略显示，悬停可查看完整名称。

## 草稿与工作区状态

每个资源维护同一个基准指纹、名称/兼容性和各已打开文件的原文与草稿。切换文件、资源、位置、设置或关闭查看区域不会丢弃草稿。侧栏草稿入口可以定位和保存全部；新建面板和未保存的目录设置也纳入退出保护。主动放弃已有修改需确认。

- 导航位置、各位置工具/类型筛选、选中资源与文件保存到 WebView 本机存储 `skilldock.workspace.v1`。偏好损坏时使用默认值；项目失效回到全局。
- 搜索、列表滚动位置、编辑器光标/滚动位置与草稿内容只在本次会话保留，不写入该偏好存储。
- 返回窗口时重新扫描；同时到达的扫描请求合并。刷新不会覆盖脏草稿；外部编辑或删除会保留草稿并阻止写入，不自动合并。
- 保存成功但扫描失败时明确提示“已保存，刷新失败”。写入后读取失败则保留已保存状态，并要求重新加载后继续编辑，避免用旧指纹再次写入。

草稿不具备崩溃恢复或跨重启持久化能力。强制结束进程、系统关机等情况不能保证保留草稿，需主动保存。

## 多文件接口与写入保护

新增 IPC `preview_edit_files`，输入采用 camelCase：

```ts
interface EditFilesInput {
  id: string;
  name: string;
  compatibility: 'both' | 'claude' | 'codex';
  files: { relativePath: string; content: string }[];
  expectedFingerprint: string;
}
```

返回原 `ChangePreview`，随后通过 `apply_changes(previewId)` 写入。一个资源内所有修改先在内存快照验证，再生成同一变更计划，保存一份完整资源备份、一条变更记录并替换文件。任何文件的路径、UTF-8/大小、元数据或指纹校验失败时不写入；重复文件项拒绝。兼容只更新元数据的空 files 列表。原 `preview_edit` 委托该流程处理单文件，保持兼容。

同名创建错误保留 `code`、`message`，额外提供可选 `existingResourceId`，用于打开实际存在的资源。原有只读、符号链接、路径、大小限制、权限保留、二次指纹校验、失败回退和历史恢复机制继续使用。已有资源目录不变。项目分组新增两张 SQLite 表，首次打开自动把既有项目关联到默认工作区，保留项目 ID 和路径。

## 退出与更新

Rust 在前端监听就绪后拦截窗口关闭及常规应用退出，通过 `workspace-exit-requested` 交给前端判断。没有修改时调用 `exit_workspace` 正常退出；有草稿时显示“保存全部并退出 / 放弃并退出 / 取消”。

“保存全部”逐个保存资源和新建草稿，最后保存目录设置；不同资源不是跨资源事务。任一项失败立即停止，成功项保持已保存，应用保留并定位失败项。正在写入或安装更新时暂缓退出。有任意未保存草稿时仍可检查更新，但暂停安装及安装后的重启重试；更新期间不能新增或编辑资源。

## 验证

- 前端自动化 56 项通过：覆盖直接保存、多文件一次应用、项目筛选记忆、草稿跨文件与跨页面恢复、冲突、只读、同名不覆盖、一次收录/删除、历史恢复、退出取消/放弃/保存失败、更新拦截，以及偏好存储不含草稿。
- Rust 自动化 36 项通过：新增批量编辑完整恢复、校验失败无部分写入、预览前后外部修改冲突、二进制拒绝、元数据单独更新和 Codex 已有指令文件定位。
- TypeScript/Vite 生产构建、Rustfmt、Clippy（`-D warnings`）与差异空白检查通过。前端仍存在原有大体积 JS chunk 提示。
- macOS 原生隔离包已构建，使用独立标识和测试目录观察 1320px 与 1040px 工作区、折叠导航、正文空间和草稿指示。窗口关闭/退出的状态流由自动化模拟原生事件验证；未完成 Windows 实机及全部字号组合的交互验收。
- 测试包关闭了更新归档生成，避免使用发行签名私钥；正式发布配置和更新签名配置保持不变。本次功能随 v0.1.8 发布，中英文说明见 `docs/testing-release-notes.md`；正式安装包由现有 GitHub Actions 工作流构建。
